# Commit

현재 변경사항을 파악하여 Porcana 앱 컨벤션에 맞는 커밋을 생성합니다.

**사용법**: `/commit [메시지]`

- 메시지를 입력하면 해당 내용을 참고해 커밋 메시지를 작성합니다.
- 메시지를 생략하면 변경사항을 분석하여 자동으로 메시지를 제안합니다.

## 커밋 메시지 규칙 (최근 커밋 로그 기반)

프로젝트는 다음 형식을 사용합니다:

```
<Type> : <내용> (한글)
```

| Type     | 용도                          |
|----------|-------------------------------|
| Feat     | 새로운 기능 추가              |
| Fix      | 버그 수정                     |
| Style    | UI/스타일 변경 (로직 무관)    |
| Refactor | 코드 리팩토링                 |
| Chore    | 빌드, 설정, 패키지 등 잡무    |
| Docs     | 문서 수정                     |
| Test     | 테스트 추가/수정              |
| Perf     | 성능 개선                     |

## 절차

1. `git status`로 변경 파일 목록 확인
2. `git diff` (staged + unstaged)로 변경 내용 파악
3. 변경 사항을 분석해 적절한 Type과 한글 메시지 제안
4. 사용자 확인 후 커밋 실행

## 주의사항

- `.env`, 시크릿 파일은 절대 커밋하지 않습니다.
- 빈 커밋은 생성하지 않습니다.
- force push, amend는 사용자가 명시적으로 요청한 경우에만 수행합니다.
- pre-commit 훅 실패 시 수정 후 새 커밋을 생성합니다 (--amend 금지).
